# Scala Flow · Queijos Scala × 75 LAB

Apresentação comercial (10 telas) do display gravitacional **Scala Flow** para o Requeijão Cremoso 1,5 kg.

Link aberto: https://projetos.75lab.com.br/scala-flow-75lab/

## Roteiro
**Começo** 01 Capa · 02 O que vimos no PDV · 03 Quem perde com a pilha
**Meio** 04 A virada · 05 A solução (anatomia) · 06 Como funciona (simulador) · 07 Jornada do shopper · 08 Realidade aumentada
**Fim** 09 O plano · 10 A próxima decisão

## Navegação
Setas, espaço ou swipe · `M` índice · `F` tela cheia · link direto por tela com `#N` (ex.: `#8` abre o AR).

## Onde trocar os renders
Os espaços de render usam os arquivos de `assets/`. Para trocar, grave a imagem nova com o mesmo nome:

| Arquivo | Onde aparece |
|---|---|
| `3d-34.webp` | Capa e tela 05 (anatomia com os pontos numerados) |
| `3d-lateral.webp` | Tela 05, aba Lateral |
| `render-frontal.webp` | Tela 05, aba Frente na geladeira |
| `render-posterior.webp` | Tela 05, aba Abastecimento |
| `3d-frente.webp` | Tela 07, jornada do shopper |

## AR
O 3D (`assets/3d/display.glb` e `display.usdz`) é o mesmo da página pública
https://projetos.75lab.com.br/ar/scala-queijos-scala-flow/ (repo `caiquebecker75/ar`).
Medidas do 3D: 31 cm de altura, 17 cm de largura e 53 cm de profundidade.

Identidade Queijos Scala levantada do site oficial (scala.com.br): vermelho `#BE1E28`, verde `#32693C`,
dourado `#BE9669`, fonte Barlow, logotipo e selo "Tradição italiana, mineira de coração".
